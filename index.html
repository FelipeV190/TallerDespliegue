Taller de Despliegue Web

Una página estática sencilla en HTML, CSS y JavaScript, lista para publicarse en Vercel.

Pasos del despliegue

1. Desarrollar

Se construye la página con HTML para la estructura, CSS para los estilos y JavaScript para la interacción.

2. Versionar

El proyecto se guarda en un repositorio de Git y se sube a GitHub para llevar el control de cambios.

3. Publicar

Con Vercel el sitio se despliega automáticamente en internet cada vez que se actualiza la rama principal.
